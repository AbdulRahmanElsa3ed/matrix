# منظومة الإنجاز والإنتاجية | Productivity & Habit Matrix 🚀

تطبيق متكامل ومرن لتتبع الأهداف الشهرية، العادات اليومية لـ 30 يوماً متصلة، والمهام الأسبوعية، مع رسوم بيانية ومؤشرات دقيقة لتذبذب الأداء ومعدلات النوم.

---

## 💻 متطلبات التشغيل
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- مدير حزم `npm` (يأتي مدمجاً مع Node.js)

---

## ⚡ خطوات التشغيل السريع (في خطوتين فقط)

1. **تثبيت الحزم والمكتبات:**
   افتح موجه الأوامر (Terminal / CMD) في مجلد المشروع ونفّذ:
   ```bash
   npm install
   ```

2. **تشغيل المشروع في وضع التطوير:**
   ```bash
   npm run dev
   ```

3. **فتح التطبيق:**
   افتح المتصفح وتوجه إلى الرابط المطبوع في الطرفية:
   `http://localhost:3000` أو `http://localhost:5173`

---

## 📦 لبناء النسخة النهائية للإنتاج (Production Build)

إذا أردت إنشاء ملفات الإنتاج الجاهزة للنشر:
```bash
npm run build
```
ستجد الملفات الناتجة داخل مجلد `dist/`.

---

## 💾 الحفظ التلقائي في ملف JSON (`data/app-data.json`)

- يتم حفظ أي تعديل تجريه على الموقع (إضافة/تعديل/حذف هدف، تغيير خانة عادة، تسجيل مهام، أو ساعات النوم) **فورياً وتلقائياً** داخل ملف:
  📁 `data/app-data.json`
- يمكنك فتح هذا الملف وتعديل البيانات مباشرة فيه أو نسخه ونقله إلى أي جهاز آخر.
- التطبيق يدعم العمل المباشر وتحديث الملف لحظياً.

---

## 🛠 التقنيات المستخدمة
- **React 19 + TypeScript**: لبناء واجهة تفاعلية قوية وآمنة الأنواع.
- **Vite**: محرك بناء فائق السرعة وخفيف الوزن.
- **Tailwind CSS**: لتنسيق الواجهات بتصميم داكن متناسق.
- **Lucide Icons**: أيقونات عصرية وسريعة الاستجابة.
- **Canvas Confetti & Web Audio API**: لمؤثرات الاحتفال والتفاعل الصوتي عند إنجاز الأهداف.
